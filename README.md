# Sistema de Logística para Transportadora

Aplicação de console desenvolvida em C# e .NET 8 para cadastrar motoristas de carreta e entregadores de moto em uma frota de transporte.

O projeto aplica os conceitos de programação orientada a objetos por meio de abstração, encapsulamento, herança e polimorfismo.
